🛒 RedStore – E-Commerce Website

RedStore is a responsive E-Commerce Website built using HTML, CSS, and JavaScript.
This project showcases a modern online shopping UI with product listings, cart functionality, and responsive design for all devices.

🚀 Live Demo

📌 Features

🏠 Home page with featured products

🛍️ Product listing page

📄 Product details page

🔢 Product quantity selection

📱 Fully responsive design (Mobile, Tablet, Desktop)

🎨 Clean and modern UI design

🔍 Smooth navigation and user-friendly layout

🛠️ Technologies Used

HTML5 – Structure of the website

CSS3 – Styling and responsive layout

JavaScript (Vanilla JS) – Interactive features
